# 공부 노트

챕터별로 **개념 정리**와 **질문 노트**를 둔다.
질문 노트는 "실험하다가 막혀서 찾아본 것"을 남기는 곳이고, 이쪽이 나중에 더 쓸모 있다.

| 챕터 | 주제 | 대응 실험 | 상태 |
|---|---|---|---|
| [ch1 — Bazel의 모델](ch1-bazel-model/README.md) | hermetic 빌드, 액션 그래프, 캐시 키 | exp01, exp02 | 진행 중 |
| [ch2 — 크로스컴파일과 타깃 실행](ch2-cross-and-target/README.md) | 플랫폼/툴체인, sysroot, QEMU | exp03, exp04, exp06 | 진행 중 |
| [ch3 — regression farm](ch3-regression-farm/README.md) | 테스트 계층, 디바이스 상태, flaky | exp05, exp07 | 시작 전 |

## 쓰는 방식

- **개념 사전**: 처음 본 용어를 한 줄로. 나중에 검색할 나를 위해.
- **질문 노트**: `qNN-<질문>.md`. 실험 중 막힌 지점 하나당 파일 하나.
  질문 → 알아낸 것 → 확인한 방법 → 남은 의문 순서.
- 추측과 확인한 사실을 **섞지 않는다.** 확인 안 한 건 "추측:"을 붙인다.
